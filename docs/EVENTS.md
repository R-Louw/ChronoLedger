# Brief sound and notification investigation

The existing allocation-expiry path in `main.c` already honors persisted notification and sound toggles. Sound currently calls `gtk_widget_error_bell()`: it is feedback, not an event sound system, and depends on desktop sound/bell settings. There are no bundled sound assets or audio dependencies in Meson.

For a small event system, use plain libcanberra (`pkg-config libcanberra`, locally installed version 0.30) with an application-owned context and short bundled, licensed samples or XDG event names. Use its core C API rather than GTK2/3 glue. Add a few named events, keep playback asynchronous, retain the existing opt-in sound switch, and coalesce simultaneous due reminders. The PulseAudio backend can use the session's PipeWire compatibility server. Missing themes/backends, muted streams and server policy can make playback silent. Completion callbacks may run on another thread: marshal any UI changes onto GTK's main context and resolve window-owned state safely. Full playback implementation and audible testing are outside this change. See the [upstream libcanberra overview](https://0pointer.de/lennart/projects/libcanberra/).

The live session's `org.freedesktop.Notifications` owner is **SwayNC**, PID 1016 at inspection. Allocation expiry already uses GIO `GNotification`; routines now reuse it with stable per-slot notification IDs and per-process due suppression. Retain that API: GTK/GIO are already dependencies, so a second libnotify subsystem is unnecessary. The installation supplies the matching `io.github.chronoledger.ChronoLedger.desktop` identity, as required by [GNotification](https://docs.gtk.org/gio/class.Notification.html). SwayNC controls presentation, DND and history; delivery does not imply visible or audible presentation. No end-to-end popup/action/DND or suspend notification test was performed. Notification clicks have no custom task/routine actions yet.

Useful future scheduling extensions: active-hours windows, weekdays, snooze, and reminders delayed until an active allocation pauses. Keep one outstanding occurrence and explicit acknowledgment semantics for these extensions.
